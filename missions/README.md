# Missions

Missions are durable, repeatable workflow patterns and examples.

They are not the same as skills:

- `skills/` define reusable instructions Codex can invoke directly
- `prompts/` define narrower role surfaces
- `missions/` package common multi-step objectives and lane shapes

Initial LHC missions:

- `incident-investigation-loop`
- `pr-build-triage`
- `service-research-sweep`
